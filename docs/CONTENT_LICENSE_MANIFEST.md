# Content license manifest

Bundled files under `assets/data/quran` and `assets/data/hadith` are treated as local copies already present in the app.

This branch does **not** rewrite Quran/Hadith JSON. Provenance is recorded in `lib/core/content/content_provenance.dart` and `docs/CONTENT_PROVENANCE.md`.

Unbundled translations (including Hindi) are honest misses.
