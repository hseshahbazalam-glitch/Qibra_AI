# Qibra AI design system

Warm ivory, deep forest, sage, and champagne gold. Light is the primary identity. Dark is a forest-night variant, not neon.

## Palette

| Role | Hex | Use |
| --- | --- | --- |
| Background | `#F5F3EC` | Screen canvas |
| Card | `#FEFDF9` | Surfaces |
| Surface | `#EEF1EA` | Soft panels |
| Primary | `#123F36` | Forest actions and type |
| Secondary | `#2F6B5D` | Sage support |
| Accent | `#C6A15B` | Thin gold only |
| Text | `#19312C` / `#71807A` | Primary / secondary |
| Border | `#E4E0D5` | Hairline dividers |

Hierarchy: about 70% ivory and white, 20% forest and sage, 10% gold.

Do not use purple, blue, bright orange, or neon green as module colors.

## Type

- English UI: Inter
- Arabic: Amiri
- Generous line height, quiet labels, no all-caps chrome unless a tiny section label

## Components

- Cards: white, 20px radius, 1px ivory border, soft forest-tinted shadow
- Primary buttons: forest fill, ivory label
- Gold is an outline or hairline, never a full-screen treatment
- Navigation: Home, Quran, Prayer, Hadith, AI, More

## Data

Use existing providers. If a value is unknown, show loading, empty, or `—`. Do not invent prayer times, weather, streaks, mosque names, or authenticity labels.
